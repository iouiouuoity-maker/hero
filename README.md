# ГЕРОЙ 360° AI — GitHub Pages + Cloudflare Workers AI + D1

## Жариялау реті
1. Cloudflare Dashboard → Workers & Pages → D1 → Create database: `hero360-class`.
2. D1 Console ішіне `schema.sql` толық SQL кодын орындаңыз.
3. Cloudflare-та **осы жобаға арналған жаңа Worker** жасаңыз. `worker.js` кодын орналастырыңыз.
4. Worker Settings → Bindings: Workers AI `AI`; D1 `DB` (hero360-class).
5. Worker Settings → Variables: `ALLOWED_ORIGIN` = `https://YOUR_USERNAME.github.io` (GitHub Pages origin; репозиторий жолын қоспаңыз).
6. Worker Settings → Secrets: `TEACHER_PASSWORD` = өзіңіз ойлап тапқан күрделі пароль (GitHub-қа салмаңыз).
7. Worker-ді Deploy жасаңыз, нақты `https://....workers.dev` URL-ін көшіріңіз.
8. `ai.js` ішіндегі `AI_API_URL` мәнін нақты Worker URL-іне **бір рет** ауыстырыңыз.
9. GitHub жаңа репозиторийіне HTML/CSS/JS және `catalog.json` файлдарын түбіріне жүктеңіз. Worker коды мен `wrangler.toml`, `schema.sql` жария сайтқа қажет емес, бірақ олар құпиясөзсіз болғандықтан репозиторийде қалуы мүмкін.
10. GitHub Settings → Pages → Deploy from branch → main / root.
11. Мұғалім `teacher-login.html` арқылы `laila.teacher` логинімен және өзі орнатқан парольмен кіреді.

## Маңызды шектеулер
- `У01`–`У11` кодтары **қорғалған оқушы аккаунттары емес**. Біреу басқа кодты таңдаса, сол кодтың жауаптарын көріп/өзгерте алады. Нақты балалармен пайдалану алдында серверлік оқушы токендерін енгізу қажет.
- Браузердегі бұрынғы жергілікті есеп/диаграмма және сервердегі D1 бағалары бөлек: мұғалім сервер панелінде нақты D1 деректерін көреді.
- Cloudflare AI тегін квотасы мен модель қолжетімділігі Cloudflare жоспарына тәуелді.
- Сайтқа оқу мәтіндерін тек пайдалануға құқығыңыз болса енгізіңіз.
- «Атамұра» Я2 оқулығының нақты толық шығармалар тізімі бұл архивте **расталмаған**. Тек мұғалім енгізетін кітапхана және бастапқы ТЗ мысалы бар. Оқулықтан шығарма атауларын ойдан қосқан жоқпыз.
- Платформа жарияланғаннан кейін браузерде және әртүрлі құрылғыларда толық тестілеу қажет.
